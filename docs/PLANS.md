운영 배포·DB 연결·DBeaver 접속 및 시작/등록/완료/수정/삭제/반별 동일 링크 흐름은 사용자가 확인했습니다. 기존 정상 흐름을 미구현으로 다시 분류하지 않습니다. 자동 백업·복구·권한·이번 수정의 배포는 별도 검증 항목입니다.

2026-09-21 반복되던 버튼 소유권 오류는 로컬 봇 두 개를 종료한 뒤 해결됐다고 사용자가 확인했습니다. 진단 당시의 원인 미확정 기록은 HISTORY에 보존하며, 검증 완화 복원과 원본 보존 보완의 운영 반영은 위 항목으로 따로 관리합니다.

## 현재 의도적으로 제공하지 않는 기능

- 누락 Slack 이벤트의 기록 전체 자동 수집·영속 작업 큐: 현재 원문 수정/재게시 또는 운영자 재처리 절차를 사용합니다.
- 공지마다 모든 학생의 Slack 성명을 다시 조회: API 호출량·지연을 늘리므로 하지 않습니다. `user_change` 이벤트가 변경된 가입자만 동기화하며 `/seulseul 시작`도 수동 복구 수단으로 유지합니다.
- 실제 폼 제출 여부 자동 확인: 완료 버튼은 학생이 직접 누릅니다.
- 일일 신규 체크리스트 DM: 최초 메시지만 계속 갱신합니다.
