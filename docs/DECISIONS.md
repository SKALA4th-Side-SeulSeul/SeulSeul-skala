## D-005 — 커밋 메시지 형식

- 날짜: 2026-09-14
- 상태: 확정
- 내용: 커밋 메시지는 `<타입>: <한국어 설명>` 형식으로 쓰고, 한 커밋에는 하나의 목적만 담습니다.

| 타입 | 용도 | 예시 |
| --- | --- | --- |
| `feat` | 기능 추가·변경 | `feat: 체크리스트 배정 서비스 추가` |
| `fix` | 버그 수정 | `fix: 마감일 없는 공지의 알림 누락 수정` |
| `refactor` | 동작 변경 없는 구조 개선 | `refactor: 공지 채널 검증 로직 분리` |
| `test` | 테스트만 추가·수정 | `test: 중복 체크리스트 생성 테스트 추가` |
| `docs` | 문서만 수정 | `docs: 커밋 규칙 정리` |
| `chore` | 설정, 의존성, 스크립트 등 | `chore: Ruff 설정 추가` |

- 이유: 제목만으로 변경 종류를 구분하고, 설명은 팀이 쓰는 언어로 통일하기 위함입니다.
