# 제품 개요

## 목표

Slack에 올라온 공지를 분석해 학생별 체크리스트로 만들고, 필요한 시점에 DM으로 알려줍니다.

## 기본 흐름

```text
Slack 공지
  → 공지 URL·채널 검증
  → 내용 요약과 마감일 추출
  → 학생별 체크리스트 생성
  → 완료 상태 관리
  → 정기 DM 알림
```

## 용어

| 용어 | 뜻 |
| --- | --- |
| 공지 | 봇이 처리 대상으로 삼는 Slack 채널에 올라온 메시지 |
| 채널·URL 검증 | 공지 메시지를 수집하는 단계. 처리할 채널의 메시지인지와 공지 URL을 확인합니다 |
| 대상 판별 | 공지가 적용되는 학생 범위를 정하는 단계. 세부 기준은 결정 전입니다 |
| 학생 | 워크스페이스 사용자 중 Slack 명령어로 알림 수신을 수락한 사람 |
| 소속 | 학생이 속한 단위. 세부 정의는 결정 전입니다 |
| 알림 설정 | 학생의 알림 수신 수락 여부 |
| 체크리스트 | 공지를 요약한 할 일. 학생마다 완료 여부를 따로 관리합니다 |
| 마감일 | AI가 공지 내용에서 추출한 기한 |

## 초기 범위 밖

- Slack 이외의 메신저 지원
- 임의의 모든 메시지에 대한 자동 처리
- 사람이 확인하지 않는 운영 정책 변경

세부 정책은 기능을 구현하기 전에 `docs/DECISIONS.md`에 기록합니다.
