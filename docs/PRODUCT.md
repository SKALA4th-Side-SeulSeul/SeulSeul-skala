# 제품 개요

## 목표

Slack에 올라온 공지를 분석해 학생별 체크리스트로 만들고, 필요한 시점에 DM으로 알려줍니다.

## 기본 흐름

```text
Slack 공지
  → 공지 URL·채널 검증
  → 내용 요약과 마감일 추출
  → 학생별 체크리스트 생성
  → 완료 상태 관리
  → 정기 DM 알림
```

## 용어

| 용어 | 뜻 |
| --- | --- |
| 공지 | 지정된 Slack 채널의 최상위 메시지 중 `form` 또는 `docs`가 URL의 호스트명이나 경로에 포함된 메시지 |
| 채널·URL 검증 | 처리할 채널의 최상위 메시지인지와 실제 URL이 D-009의 조건을 만족하는지 확인하는 단계 |
| 대상 판별 | 공지 채널과 학생 닉네임에서 판별한 캠퍼스·반을 대조해 공지가 적용되는 학생 범위를 정하는 단계 |
| 학생 | 워크스페이스 사용자 중 Slack 명령어로 알림 수신을 수락한 사람 |
| 소속 | Slack 닉네임의 `광주_<반번호>반_<이름>` 형식에서 판별한 학생의 반 |
| 알림 설정 | 학생의 알림 수신 수락 여부 |
| 체크리스트 | 공지를 요약한 할 일. 학생마다 완료 여부를 따로 관리합니다 |
| 마감일 | AI가 공지 내용에서 정확히 하나 추출한 `Asia/Seoul` 기준 기한 |

## 초기 처리 범위

- 처리 채널은 `4기_광주캠퍼스_공지`, `4기_광주캠퍼스_교육_3반`, `4기_교육생_전체공지`입니다.
- 스레드 답글과 SeulSeul 봇 자신이 작성한 메시지는 처리하지 않습니다.
- `4기_교육생_전체공지`와 `4기_광주캠퍼스_공지`는 등록된 광주캠퍼스 학생 전체에게 배정합니다.
- `4기_광주캠퍼스_교육_3반`은 닉네임에서 광주캠퍼스 3반으로 판별된 학생에게만 배정합니다.
- 원본 공지의 수정·삭제는 기존 학생별 체크리스트에도 반영합니다.

## 초기 범위 밖

- Slack 이외의 메신저 지원
- 임의의 모든 메시지에 대한 자동 처리
- 사람이 확인하지 않는 운영 정책 변경

세부 정책은 기능을 구현하기 전에 `docs/DECISIONS.md`에 기록합니다. 현재 공지 수집·대상 판별·AI 분석·중복 처리 정책은 D-009~D-012를 따릅니다.
