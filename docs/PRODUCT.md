# 제품 개요

## 목표

Slack에 올라온 공지를 분석해 학생별 체크리스트로 만들고, 필요한 시점에 DM으로 알려줍니다.

## 기본 흐름

```text
Slack 공지
  → 공지 URL·채널 검증
  → 내용 요약과 마감일 추출
  → 학생별 체크리스트 생성
  → 오전 9시 개인 DM / 이후 당일 메시지 갱신
  → DM 버튼으로 완료·완료 취소
```

## 용어

| 용어 | 뜻 |
| --- | --- |
| 공지 | 지정된 Slack 채널의 최상위 메시지에서 발견한, `form` 또는 `docs`가 URL의 호스트명이나 경로에 포함된 링크 하나 |
| 채널·URL 검증 | 처리할 채널의 최상위 메시지인지와 실제 URL이 D-009의 조건을 만족하는지 확인하는 단계 |
| 대상 판별 | 공지 채널과 학생 성명에서 판별한 캠퍼스·반을 대조해 공지가 적용되는 학생 범위를 정하는 단계 |
| 학생 | 워크스페이스 사용자 중 Slack 명령어로 알림 수신을 수락한 사람 |
| 소속 | Slack 성명(`profile.real_name`)의 `4기_광주_<반번호>반_<이름>` 형식에서 판별한 학생의 반. 반 번호는 1~4 |
| 알림 설정 | 학생의 알림 수신 수락 여부 |
| 체크리스트 | 공지를 요약한 할 일. 학생마다 완료 여부를 따로 관리합니다 |
| 마감일 | AI가 공지 내용에서 정확히 하나 추출한 `Asia/Seoul` 기준 기한 |

## 초기 처리 범위

- 처리 채널은 기수 전체 공지 채널, 캠퍼스 공지 채널, 담당 반 공지 채널 3곳입니다. 실제 채널 ID는 공개 저장소에 적지 않고 `.env`의 `SLACK_NOTICE_CHANNELS`에만 둡니다.
- 스레드 답글과 SeulSeul 봇 자신이 작성한 메시지는 처리하지 않습니다.
- 처리 조건을 만족하는 링크 하나를 공지 하나로 봅니다. 한 메시지에 여러 링크가 있으면 링크마다 별도의 체크리스트를 만듭니다.
- 기수 전체 공지 채널과 캠퍼스 공지 채널의 공지는 등록된 광주캠퍼스 학생 전체에게 배정합니다.
- 담당 반 공지 채널의 공지는 성명에서 광주캠퍼스 3반으로 판별된 학생에게만 배정합니다.
- 원본 공지의 수정·삭제는 기존 학생별 체크리스트에도 반영합니다.
- 사용자 응답에는 공지 원문 전체를 반복하지 않고 Slack 원문 위치로 이동하는 링크를 제공합니다.
- 사용자는 `/seulseul 시작`으로 가입을 요청한 뒤 성명 검증을 받고, `/seulseul 해지`로 개인 정보와 개인 체크리스트를 삭제합니다.
- 학생용 조회 명령은 제공하지 않습니다. 오전 9시에 본인에게 배정된 마감 전 미완료 항목을 DM으로 받고, 이후 새 공지와 상태 변경은 같은 날짜 메시지에 반영합니다. 완료 항목 보기·완료 취소·페이지 이동도 DM 버튼으로 처리합니다(D-023).
- 할 일이 없어도 오전 9시에 빈 목록을 보냅니다. 9시 이후 가입·봇 복구 시 당일 미발송 메시지를 보충하고, 0~9시에는 새 DM을 보내지 않습니다. 이전 날짜 버튼으로는 변경할 수 없습니다.
- AI 분석에 실패한 공지는 운영자용 CLI에서 선택해 재처리합니다(D-022). 학생이 공지를 조회하거나 같은 링크를 다시 게시하는 것만으로 재분석하지 않습니다.

## 초기 범위 밖

- Slack 이외의 메신저 지원
- 임의의 모든 메시지에 대한 자동 처리
- 사람이 확인하지 않는 운영 정책 변경

세부 정책은 기능을 구현하기 전에 `docs/DECISIONS.md`에 기록합니다. 공지 수집·대상 판별·AI 분석·중복 처리는 D-009~D-019, 성명 판별은 D-021, 운영자 선택 재처리는 D-022를 따릅니다. 사용자 명령·일일 DM·완료 상태 화면은 D-023이 D-021의 조회 명령과 D-022의 미구현 배정·DM 범위를 대체합니다.
