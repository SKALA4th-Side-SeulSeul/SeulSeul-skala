# 제품 개요

## 목표

Slack에 올라온 공지를 분석해 학생별 체크리스트로 만들고, 필요한 시점에 DM으로 알려줍니다.

## 기본 흐름

```text
Slack 공지
  → 공지 URL·채널 검증
  → 내용 요약과 마감일 추출
  → 학생별 체크리스트 생성
  → 완료 상태 관리
  → 정기 DM 알림
```

## 초기 범위 밖

- Slack 이외의 메신저 지원
- 임의의 모든 메시지에 대한 자동 처리
- 사람이 확인하지 않는 운영 정책 변경

세부 정책은 기능을 구현하기 전에 `docs/DECISIONS.md`에 기록합니다.
